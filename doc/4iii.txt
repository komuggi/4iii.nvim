1. はじめに                                                      *4iii-intro*

作品のフォルダに `4iii.lua` を置くと、そのフォルダ（とその下）の `.txt` が
台本として開かれます。

>text
    作品フォルダ/
    ├── 4iii.lua      作品ごとの設定（return {} だけでもよい）
    ├── 台本.txt         台本。見出しで区切って1ファイルに書く
    ├── parts/          塊（{名前}）の中身
    └── out/            書き出した PDF・.md・.docx
<

全部の作品に効く設定は |4iii.setup()| に、作品ごとの設定はその作品の
`4iii.lua` に書きます。同じ書き方で、作品ごとの方が上書きします。

                                                               *4iii.setup()*
>lua
    require("4iii").setup({
      -- ここに |4iii-config| の設定
    })
<

2. 台本の書き方                                                *4iii-writing*

行の頭の記号で、行の種類を見分けます。どれにも当たらない行がセリフです。

    行の頭      種類    書き出し    文字数 ~
    なし        セリフ  出す        数える
    `//`        指示    出す        数えない
    `(` `（`    場面    出す        数えない
    `【`        位置    出す        数えない
    `¥` `￥`    メモ    出さない    数えない
    `#` `##`    見出し  出す        `##` ごとに数える

記号と種類は `line_types` で自分で決められます（|4iii-config|）。

                                                              *4iii-hankaku*
日本語入力のまま打った記号は、記号として使う場所でだけ半角にします
（`hankaku = false` で止められます）。セリフの中の全角はそのままです。

    `／／` `＃` `（` `￥`   行の頭
    `）`              `(` で始まる行
    `｛` `｝`          どこでも
    `：`              `// SE` のすぐあと
    全角の空白        `#` や `//` のすぐあと

複数人の台本は `mode = "multi"` にして、`名前「セリフ」`（`multi.style =
"kagi"`）か `名前：セリフ`（`"colon"`）で書きます。名前とかっこは数えません。

囲い指示                                                        *4iii-ranges*

行の頭（または指示・場面の行の頭）に `▼ラベル` を書くと範囲が始まり、
`▲ラベル` で終わります。範囲の行は文字数に入りません。
>text
    ▼右・近
    ここから ▲ の行までが、ひとつの範囲です
    ▲右・近

    // ▼右・近      ← この書き方も使えます
<
- 範囲は重ねてよく、閉じる順番は問いません
- 閉じのラベルは、開いたラベルの頭だけでもかまいません
  （`▼口元→ささやき` を `▲口元` で閉じられる）。空白の違いは無視します
- 閉じ忘れと、開いていない範囲を閉じたときに警告を出します
  （見出しをまたぐ範囲も閉じ忘れとみなします）
- `▼` を打つと、ラベルの候補が出ます。この台本で使ったラベル（多い順）、
  位置×距離（`前・近` など）、`ranges.words` の言葉の順です
- `▲` を打つと、まだ閉じていないラベルが候補に出ます
- 打ちかけのラベルは `<C-x><C-o>` で候補を出せます

早く出す（どれも設定で止められます）:
- `▼ラベル` の行で改行すると、下に `▲ラベル` が入ります（`ranges.auto_close`）
- 行の頭で `[[` と打つと `▼`、`]]` で `▲` になります。日本語入力の `「「`
  `」」` でもなります（`ranges.brackets`）
- `<localleader>[` で下に `▼` の行を作って候補を出します。行を選んで押すと、
  選んだ行を `▼`〜`▲` で囲みます。`<localleader>]` で `▲` の行を作ります

範囲の中の行の左には、縦の線を出します（画面だけ。ファイルには入りません）。
範囲が重なると線が増え、ラベルごとに色が変わります（`ranges.guides`）。

言葉の候補                                                       *4iii-words*

- `// SE : ` と打つと、SE の候補が出ます。`words.se` に登録した言葉が先、
  この台本で使った SE（多い順）があとです。`・` や `、` のあとも出ます。
  登録しておくと、「衣擦れ」「衣擦れ音」のような書き方の揺れがそろいます
- 指示の行で `<C-x><C-o>` を押すと、`words.shiji` に登録した言葉と、
  この台本で使った指示が出ます（打つたびには出しません）
>lua
    words = {
      se = { "衣擦れ", "足音", "ドアが開く" },
      shiji = { "耳元で", "吐息まじりに" },
    },
<

==============================================================================
3. 塊                                                            *4iii-parts*

よく使う文章を `parts/名前.txt` に置き、台本には `{名前}` と書きます。
文字数は中身で数え、書き出すと中身に置き換わります。
>text
    {いつもの}           閉じている

    {{いつもの           開いている（その場で中身を直せる）
    ここからは、parts/いつもの.txt の中身です
    }}
<
- `<localleader>b`（`:dh toggle`）で開く／閉じる。中身を変えて閉じると、
  「この場所だけ直す」か「元の塊も直す」かを聞きます
- `{名前}` の上で `K` を押すと、中身と文字数を小窓に出します
- `<localleader>p`（`:dh pick`）で一覧から選んで差し込みます。
  snacks.nvim があれば、中身を横に出します
- `{{新しい名前` 〜 `}}` と書いて保存すると、`parts/` に新しく作ります。
  中身のない `{新しい名前}` は警告だけ出します
- 塊の名前に `/` や先頭の `.` は使えません

`@` で始まる名前は、書き出すときに作る組み込みの塊です。

    `{@文字数一覧}`   見出しごとの文字数と合計の一覧（仕様書に）

==============================================================================
4. 文字数                                                        *4iii-count*

空白と改行を除いて数えます。既定ではセリフだけを数えます。

- カーソルのあるトラックと全体の文字数を、いつも出します
  （`Track 01 行の種類 137文字 ／ 全体 418文字`）。出す場所は
  `show_count` で選べます

    `"winbar"`      ウィンドウの上の帯（既定）
    `"float"`       右上の小窓
    `"statusline"`  下の帯。自分で足す（下の例）
    `false`         出さない

>lua
    -- lualine の例
    sections = { lualine_x = { require("4iii").status } }
<
- `count = true` の見出しの横に、その見出しの下の文字数を出します
- `count.long_line`（既定 30）より長いセリフに、薄い印を付けます
- `:dh count` で、全体と見出しごとの文字数を、セリフだけとト書きも数えた
  ときの両方で出します

5. 書き出し                                                     *4iii-export*

`:dh pdf` で、作品フォルダの `out/` に PDF を作ります。
`台本_ト書きあり.pdf` と `台本_ト書きなし.pdf` の2つです。`:dh html` は
HTML だけを作ります。PDF を作るには Vivliostyle CLI が要ります。
>sh
    npm install -g @vivliostyle/cli
<
- メモ（`¥`）と塊の目印は出しません。`{名前}` は中身に置き換えます
- `count = true` の見出しには `show` の形で文字数を付けます
- 既定は A4 横の縦書き、BIZ UDP明朝 12pt です（なければヒラギノ明朝など）
- 縦書きでは `▼` `▲` を `◀` `▶` にします（`vertical_marks`）
- セリフは字下げし、ト書きは行の頭から書きます

見た目をもっと細かく変えたいときは、自分の CSS を `export.pdf.css` に書きます。
行のクラス名は、セリフが `serifu`、ほかは `t-種類の名前`（`t-指示` など）です。
>css
    .t-指示 { color: gray; }
<

Google ドキュメント・Word で渡すとき                      *4iii-export-md*

`:dh md` で Markdown（`.md`）、`:dh docx` で Word（`.docx`）を、PDF と同じ
`out/` に書き出します。ト書きあり／なし・見出しの文字数・`{名前}` の中身・
メモを出さない決まりは PDF と同じです（`both = false` なら、ト書きありだけ）。
どちらも外の道具は使いません。

- `.md` は横書きです。Google ドライブに置くと、Google ドキュメントでそのまま
  開いて、コメントや共同編集ができます。ト書きは斜体、話す人の名前は太字です
- `.docx` は `export.pdf` の縦書き・紙・余白・字・字下げ・改ページ・ページ
  番号に合わせます。セリフ・ト書き・指示は Word のスタイルなので、受け取った
  人が Word で見た目を変えられます。`export.pdf.css` は使いません

==============================================================================
6. コマンドとキー                                            *4iii-commands*

                                                                         *:Dh*
:Dh {やること}      小文字の `:dh` でも打てます（行の頭の `dh` を `Dh` に
                    置き換えます。いらなければ `setup({ lower_dh = false })`）

    `:dh pdf`       PDF に書き出す
    `:dh html`      HTML だけ書き出す
    `:dh md`        Markdown に書き出す（Google ドキュメントで開く用）
    `:dh docx`      Word に書き出す
    `:dh count`     文字数の一覧
    `:dh pick`      塊の一覧から差し込む
    `:dh toggle`    塊を開く／閉じる

台本のバッファにだけ付くキー（`keys` で変えられます。`false` で付けない）:

    `<localleader>b`  塊を開く／閉じる
    `<localleader>p`  塊の一覧から差し込む
    `K`               塊の中身を見る
    `<localleader>[`  下に ▼ の行を作る（行を選んで押すと ▼〜▲ で囲む）
    `<localleader>]`  下に ▲ の行を作る

7. 設定                                                         *4iii-config*

既定値です。書いたところだけ上書きされます。`line_types` などのリストは、
書くと丸ごと置き換わります（足すのではなく、全部書き直す）。
>lua
    {
      mode = "solo",               -- "solo"（1人）／"multi"（複数人）
      multi = { style = "kagi" },  -- "kagi" = 名前「セリフ」／"colon" = 名前：セリフ

      -- 上から順に見て、最初に当てはまったもの。どれにも当たらない行がセリフ
      line_types = {
        { name = "メモ", prefix = { "¥", "￥" }, output = false, hl = "4iiiMemo" },
        { name = "指示", prefix = "//", hl = "4iiiShiji" },
        { name = "位置", prefix = "【", suffix = "】", hl = "4iiiIchi" },
        { name = "場面", prefix = { "(", "（" }, suffix = { ")", "）" }, hl = "4iiiBamen" },
      },

      ranges = {
        open = "▼", close = "▲", in_types = { "指示", "場面" },
        position = { "前", "右前", "左前", "右", "左" },  -- ▼ の候補：位置
        distance = { "遠", "中", "近", "密" },            -- ▼ の候補：距離
        sep = "・",
        words = {},                                        -- ▼ の候補：そのほかの言葉
        auto_close = true,                                 -- 改行で ▲ を入れる
        brackets = true,                                   -- [[ ]] を ▼ ▲ に
        guides = true,                                     -- 縦の線
      },

      headings = {
        { level = 1, prefix = "# " },
        { level = 2, prefix = "## ", count = true, show = "%s : %s文字" },
      },

      count = {
        include = { "セリフ" },  -- ト書きも数えるなら { "セリフ", "指示", "位置", "場面" }
        ignore_chars = "",       -- 数えない記号。例 "…、。"
        long_line = 30,          -- これより長いセリフに印。false で付けない
      },

      words = {
        se = {},                   -- 「// SE : 」のあとに出す言葉
        shiji = {},                -- 指示の行で <C-x><C-o> を押すと出す言葉
      },

      hankaku = true,              -- 記号を半角にする（|4iii-hankaku|）
      parts_dir = "parts",
      show_count = "winbar",     -- "winbar"／"float"／"statusline"／false

      keys = {
        toggle = "<localleader>b", pick = "<localleader>p", hover = "K",
        range_open = "<localleader>[", range_close = "<localleader>]",
      },

      export = {
        dir = "out",
        pdf = {
          vertical = true,         -- false で横書き
          both = true,             -- ト書きなしも出す（md・docx も）
          size = "A4 landscape",
          margin = "20mm",
          font = '"BIZ UDPMincho", "BIZ UDP明朝 Medium", "Hiragino Mincho ProN", serif',
          font_size = "12pt",
          line_height = 1.8,
          page_number = true,
          new_page = 2,            -- この段までの見出しで改ページ。false でしない
          serifu_indent = "3em",
          vertical_marks = { open = "◀", close = "▶" },  -- false でそのまま
          css = nil,               -- 自分の CSS（作品フォルダからの場所）
          command = nil,           -- PDF を作るコマンド。setup() でだけ変えられる
        },
      },
    }
<

8. 色                                                       *4iii-highlights*

既存の色につないであります。`:hi` で変えられます。

    4iiiHeading   見出し          (Title)
    4iiiShiji     指示            (Comment)
    4iiiIchi      位置            (Type)
    4iiiBamen     場面            (Special)
    4iiiMemo      メモ            (NonText)
    4iiiRange     ▼ ▲ のラベル    (Keyword)
    4iiiSpeaker   話す人の名前    (Identifier)
    4iiiBlock     塊の名前        (Constant)
    4iiiCount     文字数の表示    (Comment)
    4iiiGuide1〜6 範囲の縦の線    (DiagnosticInfo など)

9. 安全のために                                                *4iii-safety*

- 作品フォルダの `4iii.lua` は、何にも触れない空の環境で読みます。
  nvim の機能・ファイル・コマンドは使えず、できるのは設定の表を返すことだけ
  です。長すぎる・大きすぎるときは途中で止めます
- PDF を作るコマンド（`export.pdf.command`）は |4iii.setup()| でだけ変え
  られます。`4iii.lua` に書いても無視します
- `parts_dir`・`export.dir`・`export.pdf.css` は作品フォルダの中しか指せません
- 通信はしません。PDF は、入れておいた `vivliostyle` を、シェルを通さずに
  呼ぶだけです。`.md`・`.docx` は 4iii の中だけで作ります
